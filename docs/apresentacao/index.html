Ponto de partida

RPython é uma linguagem didática com sintaxe de Python e tipos estáticos

# examples/hello.rpy
val name = "World";
var _ = print("Hello, ");
var _ = print_line(name);

val x = 10;
val y = 20;
val sum = x + y;

asserttrue(sum == 30, "sum should be 30");
  • Implementada em Rust, para ensinar implementação de linguagens.
  • Blocos abertos por : e fechados por end; statements separados por ;.
  • Tem funções, listas, tuplas, ADTs, lambdas e testes embutidos.
  • Não tem objetos, métodos nem acesso a atributos.
$ cargo run -- examples/hello.rpy Hello, World 10 + 20 = 30

Orientação do professor

Por isso: profundidade no parser em vez de amplitude pelo compilador inteiro. A exploração inicial (PR #2) já ia até o interpretador; ela serviu de estudo, mas não é a entrega.

Parser antes da mudança

Uma cascata de alt para statements e uma escada de precedência para expressões

parse() em src/parser/mod.rs lê uma lista de statements separados por ;.

parse_statement tenta cada alternativa em ordem; a primeira que casa vence. Palavras-chave vêm antes, atribuição e expressão ficam por último.

Blocos (parse_block) são : + statements + end, e viram Statement::Block.

Cada parser devolve IResult<&str, T>: o resto da entrada e o nó produzido.

parse_or
parse_and
parse_not
parse_relational < <= == !=
parse_add_sub + -
parse_term * /
parse_factor literais, variáveis, chamadas, parênteses

Sintaxe

Gramática adicionada

class_def ::= class IDENT : [ member { ; member } [;] ] end member ::= field | method field ::= ( val | var ) IDENT : type = expr method ::= func_def -- o primeiro parâmetro deve se chamar self type ::= ... | IDENT -- nome de classe, tentado por último factor ::= primary { . IDENT [ ( args ) ] } field_asg ::= factor = expr -- o factor deve terminar em .IDENT primary ::= bool | number | string | list | call | var | ( ... ) | lambda -- antigo factor, sem mudança

pub fn parse_factor(input) {
  let (input, init) = parse_primary(input)?;
  fold_many0(
    preceded(char('.'),
      pair(identifier, opt(parse_actual_arguments))),
    // Some(args) => MethodCall, None => FieldAccess
  )
}

src/ir/ast.rs

Seis adições na AST, nenhuma variante existente alterada

pub struct FieldDeclaration {
    pub name: Name,
    pub field_type: Type,
    pub mutable: bool,        // var = true, val = false
    pub initializer: Box<Expression>,
}

pub struct Class {
    pub name: Name,
    pub fields: Vec<FieldDeclaration>,
    pub methods: Vec<Function>,  // reaproveita Function
}
pub enum Type {
    ...
    TClass(Name),             // self: Point
}

pub enum Expression {
    ...
    FieldAccess(Box<Expression>, Name),
    MethodCall(Box<Expression>, Name, Vec<Expression>),
}

pub enum Statement {
    ...
    ClassDef(Class),
    FieldAssignment(Box<Expression>, Name, Box<Expression>),
}

Ficaram de fora de propósito: New (instanciação, Point() continua sendo FuncCall) e ClassInstance (valor de runtime).

examples/classes/point_full.rpy

O exemplo da proposta é aceito inteiro pelo parser

class Point:
    var x: Int = 0;
    var y: Int = 0;

    def init(self: Point, x: Int, y: Int) -> Unit:
        self.x = x;
        self.y = y;
    end;

    def get_x(self: Point) -> Int:
        return self.x;
    end;
end;

val p = Point();
p.init(3, 4);
val px = p.get_x();
assert(px == 3, "x deveria ser 3");
